## Suggested records

- Requirements: ID, source, required/conditional status, owner, acceptance check and evidence.
- Architecture: components, responsibilities, input/output flow and deployment environment.
- Shared interface: formats, units/ranges, transport, status/errors, timing/timeouts, manual/AI priority, stop/reset and access rules.
- Approach decision: question, options, evidence, selected approach, tradeoff and remaining gap.

For model integration, document camera/state fields, preprocessing, action scaling and control mapping.
