# Franka Emika Panda URDF & Visual Meshes

- **Model:** 7-DOF Franka Emika Panda arm + Panda parallel-jaw hand (`panda.urdf`)
- **Kinematics:** Matches `robosuite` v1.4.0 (`robots/panda/robot.xml` and `grippers/panda_gripper.xml`), the simulator used by LIBERO.
- **Visual meshes (`meshes/*_vis.stl`):** Sourced from `franka_description` v0.7.0 as packaged with `robosuite` v1.4.0.
