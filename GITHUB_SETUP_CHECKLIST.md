# GitHub setup checklist

This is a checklist of repository settings and team decisions. Creating these files does not configure GitHub settings.

## Local template files

- [x] Root guides: README, folder guide, Drive index, contributing guide, evidence policy and this checklist.
- [x] Source and test folders with starter guides.
- [x] Research folders: literature, methodology, experiments and results.
- [x] Documentation folders: technical and project management.
- [x] Evidence indexes: product, research, process and individual.
- [x] AI assistance notes, data index and handover guides.
- [x] Git ignore rules, task/bug/research issue forms and pull request template.
- [x] Workflow folder with guidance; automated build and test workflows await agreed commands.

## Repository and access

- [ ] Confirm repository name, description and visibility.
- [ ] Add teammates with the agreed permissions.
- [ ] Assign maintainers and reviewers for AI, IoT, SoftDev and integration.
- [ ] Decide the repository licence and check licences of reused code, data and models.
- [ ] Decide whether this repository should be marked as a GitHub template repository.

## Workflow

- [ ] Confirm the Jira project key and issue-link convention.
- [ ] Review the issue forms and PR template.
- [ ] Enable the desired branch protection or ruleset on the default branch.
- [ ] Agree review requirements and merge policy.
- [ ] Decide which automated checks are required before merging.
- [ ] Add workflows only after their commands and environment are reproducible.
- [ ] Confirm handling of secrets and large datasets/model files.

## Documentation and evidence

- [ ] Add the missing links in GOOGLE_DRIVE_INDEX.md.
- [ ] Assign owners for the shared interface and acceptance targets.
- [ ] Agree evidence review and individual contribution records.
- [ ] Confirm the official AI Usage Log location.
- [ ] Review setup and deployment instructions before handover.
